# Momento 1 - Cajero Banco Mi Plata

Proyecto realizado para el taller de programación en JavaScript.

## Descripción

Aplicación de consola que simula las operaciones básicas de un banco llamado **Mi Plata**. El sistema utiliza `prompt()` para solicitar información al usuario, `console.log()` para mostrar mensajes y `localStorage` para almacenar los datos.

## Funcionalidades

- Registro de nuevos usuarios.
- Validación de nombre de usuario repetido.
- Registro de nombre, clave y saldo inicial.
- Inicio de sesión con usuario y contraseña.
- Máximo de tres intentos de inicio de sesión.
- Bloqueo de cuenta después de tres intentos fallidos.
- Retiro de dinero con validación de saldo.
- Consulta de saldo.
- Consignación de dinero.
- Consulta de movimientos.
- Registro de fecha, tipo y monto de cada movimiento.
- Almacenamiento de información mediante `localStorage`.
